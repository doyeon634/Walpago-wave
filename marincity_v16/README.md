# 마린시티 호안 월파 위험 예측 (v16) · 팀 월파고

EurOtop (2018) 6장 경사식 호안 공식으로 학습 데이터를 만들고(1차), Random Forest로 학습한 뒤(2차),
파고·주기·여유고를 넣으면 위험 등급과 월파 모습을 보여 주는 대시보드(3차)를 만듭니다.

## 폴더
```
marincity_v16/
├─ config.yaml            모든 값과 근거 ([가정] 표시 값은 자료 확보 후 교체)
├─ overtopping.py         공통 계산 모듈 (EurOtop 식)
├─ requirements.txt
├─ step1_data/            1차: 학습 데이터 생성
│   ├─ generate_data.py
│   └─ output/            scenarios.csv, eval_*.csv, filter_log.csv, validation_report.md, data_card.md, coverage.png
├─ step2_model/           2차: 모델 학습
│   ├─ train_model.py
│   └─ output/            rf_model.joblib, model_meta.json, model_report.md, calibration.png
└─ step3_dashboard/       3차: 대시보드
    ├─ app.py
    ├─ threescene.py      월파 모습 3D 장면 (three.js)을 만드는 모듈
    ├─ scene_template.html 3D 장면 본체 (바다·TTP·파라펫·배후지·건물, 처오름·덮침·물보라·땅 위 흐름)
    ├─ vendor/            three.js r128 (인터넷 없이 동작, MIT 라이선스)
    ├─ section_canvas.py  2D 단면 그림 (실사형 + 치수)을 만드는 모듈
    ├─ section_template.html 2D 단면 본체 (HTML 캔버스 애니메이션)
    ├─ section2d.py       대시보드 숫자 칸에 쓰는 단면 계산 (처오름, 낙하 거리 등)
    └─ .streamlit/config.toml   화면 테마 (어두운 색)
```

## 실행 (Windows PowerShell)
```powershell
cd "프로젝트 폴더 경로\marincity_v16"
py -m pip install -r requirements.txt

py step1_data\generate_data.py          # 1차 (수 초)
py step1_data\export_excel.py           # 1차 결과를 엑셀로 (확인용, 선택)
py step2_model\train_model.py           # 2차 (1분 안팎)

cd step3_dashboard
py -m streamlit run app.py              # 3차
```
- `py step1_data\generate_data.py --check` : 같은 설정·시드로 다시 만들어 결과가 같은지 확인
- config.yaml을 바꾸면 1차 → 2차 순서로 다시 실행하세요. 대시보드는 새 모델을 자동으로 읽습니다.

## 단계별 내용
**전제 조건 (단면 고정)**: 태풍 차바(2016) 당시 제방. TTP 16 t 2층(마루 DL+4.0 m) + 사석 코어 + 콘크리트 직립벽 + 2012년 방파벽(꼭대기 DL+6.3 m), 산책로 DL+5.1 m, 보행로 6 m, 도로 17.5 m, 사면 1:1.5, 수심 10.5 m, 조도계수 γf 0.47, 정면 입사. 여유고 범위 2.3~6.3 m (정수위 DL 0 ~ TTP 마루 DL+4.0).

**1차 학습 데이터 (혼합 방식)**: 3,000건
- A 격자 1,870건: 파고 0.5 m부터 0.6 m 간격(11단계) × 주기(파고마다 가능한 범위를 10단계 같은 간격) × 여유고 2.3 m부터 0.25 m 간격(17단계)
- B 경계 집중 930건: 등급 경계 근처 Sobol 표본(기각 샘플링). 격자에서 칸당 100건이 안 되는 칸을 먼저 보충
- C 범위 가장자리 200건
- 쇄파 한계(파고 ≤ 0.65 × 수심) 필터, 학습 70 / 검증 15 / 시험 15 층화 분할, 평가 전용 경계 시험 300건·범위 밖 시험 200건
- 정답 라벨은 EurOtop 경사식 공식(평균값 접근). 엑셀 확인용 파일: step1_data/output/학습데이터_확인용.xlsx

**등급 기준 (국내, KDS 64 10 10 : 2020 해설 참고 표 4.3-9, 4.3-10)**

| 기준 | 허용 월파량 | 쓰임 |
|---|---|---|
| 차량 (운전 가능) | 2×10⁻⁵ m³/m·s = 0.02 l/s/m | 안전/주의 경계 (사람 기준보다 엄격) |
| 사람 (보행 위험 없음) | 3×10⁻⁵ = 0.03 l/s/m | 설명·그림 표시 |
| 가옥 (위험 없음) | 7×10⁻⁵ = 0.07 l/s/m | 건물 피해 가능 표시 |
| 아무것도 없을 때 (배후 민가·공공시설 밀집) | 0.01 = 10 l/s/m | 주의/위험 경계 |

**2차 모델**: 등급 모델과 건물 피해 모델(Random Forest). 사용자 입력은 3개이고, 모델 안에서 이 셋으로 계산한
무차원 여유고 Rc/Hs와 파형경사를 함께 씀(시험 정확도 98.9%). 확률 보정 여부를 Brier 점수로 결정.

**3차 대시보드** (v16: 2D 시뮬레이션에서 월파 직전 물이 사라지던 문제 수정 · v15: 슬라이더 아래 작은 '차바' 버튼, 2D 시뮬레이션은 규칙파로 호안을 넘음·입자 0.36 m · v14: v13: '2D 시뮬레이션' 보기 추가 — 물을 입자로 직접 계산, 컴퓨터 성능에 맞춰 입자 수 자동 최대 · v12: 방파벽 전체를 위험 등급 색으로 진하게, 위험이면 깜빡임 · v11: 상단에 팀 이름·마크, 단면에 기초사석·피복석을 빈틈없이 채움, TTP 틈에서 솟는 물보라 제거 · v10: 처오름을 따로 떠 있는 물 판 대신 바다 면이 그대로 이어져 TTP를 타고 오르게 · v9: 바다를 부드러운 곡면과 거품 무늬로, 월파를 사진처럼 하얗게 피어오르는 물보라 기둥으로, 3D 기본 시점을 '도로에서'로 · v6: 3D·2D 모두 실제 파도 높이로 덮치는 모습, 일반인용 쉬운 문구, '가장 큰 파도 보기' 버튼,
2D 는 기본으로 꼭 필요한 글자만 보이고 '자세히 보기'로 치수·표고를 켬): 전제 조건 표시 → 입력(가능 조건 범위로 제한, 주기는 파고에 따라 범위가 바뀜) → AI 위험 등급
→ 반원 게이지(AI·경험식) → 월파량과 적용 공식 → 허용 월파량 표(국내 기준) → 월파 모습(사실적인 3D 장면·2D 단면)
→ 계산 과정 → 여유고–월파량 그래프 → 파라미터(현재 값·범위).

## 교수님께 보고할 점
- 불가능 칸: 쇄파×안전 (수심에 비해 큰 파도는 여유고 8 m에서도 차량 기준 이상 월파).
- 설계안과 다른 점: A(공간 균등)를 Sobol 층화 대신 같은 간격 격자로 바꿈(10/29 결정). 격자만 쓰면 시험 정확도 92%,
  혼합 방식은 97.8%로 기존(Sobol)과 같은 수준.
- 국내 기준은 차량(0.02)이 사람(0.03)보다 엄격해서, 안전/주의 경계는 차량 기준을 씀.
- 국내 기준값이 매우 작아(0.001~0.07 l/s/m), EurOtop 실험 자료 범위보다 작은 월파량까지 공식을 외삽함.
- 경험식 확률: EurOtop 6.3.1절 계수 표준편차(σ(0.09)=0.0135, σ(1.5)=0.15)로 몬테카를로 계산.
- 3D·2D 그림은 경험식 결과를 그린 것이며 물 흐름 시뮬레이션이 아님.
- 넘어오는 파도 수: 대시보드 숫자 칸과 3D 그림 모두 식 6.3(처오름 레일리 분포) 하나로 통일.
  EurOtop은 식 6.3이 사석 경사제에서 넘는 파도 수를 많게(안전 쪽으로) 준다고 설명함.

## 교체해야 할 가정 (config.yaml)
`water_depth_h`(수심, 지금 10.5 m), `cot_alpha`(사면 경사), `breaker_limit`(쇄파 한계), `crest_width_m`(천단폭),
`ranges`(파고·파형경사·여유고 범위), `dashboard.section`(도로 폭·건물 위치, 그림용)
